# Poll & Quiz Creator Bot 🤖

A Telegram bot that allows users to create interactive polls and quizzes directly in their chats.

## Features ✨

- **Create Polls**: Create polls with multiple options
- **Create Quizzes**: Create quizzes with correct answers
- **Interactive UI**: Inline keyboards for easy navigation
- **Anonymous Voting**: Polls support anonymous voting
- **Real-time Results**: See results as they come in

## Commands 📝

- `/start` - Start the bot
- `/poll` - Create a new poll
- `/quiz` - Create a new quiz
- `/help` - Show help message
- `/cancel` - Cancel current operation
